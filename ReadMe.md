# 🧠 Online Aptitude Test System

An interactive web-based aptitude examination platform designed to simplify the process of conducting, managing, and evaluating online tests.

The system allows students to take aptitude tests in a structured environment while providing administrators with tools to manage questions, monitor results, and oversee user activities. The platform automates evaluation and delivers instant feedback, making the assessment process efficient and scalable.

---

## 🚀 Features

### 👨‍🎓 Student Features

- Secure user authentication
- Take aptitude tests online
- Timed examinations
- Instant result generation
- Score tracking and performance monitoring
- User-friendly interface

### 👨‍💼 Admin Features

- Manage students and user accounts
- Add, edit, and delete questions
- Create and manage tests
- View examination results
- Monitor participant performance
- Maintain question database

### ⚡ System Features

- Automated evaluation system
- Multiple-choice question support
- Fast and accurate result processing
- Responsive design
- Organized database structure
- Easy deployment and maintenance

## ⚙️ Installation

### 1. Clone the Repository

```bash
git clone https://github.com/AhmedHaneen071/Online-Aptitude-Test-System.git
```

### 2. Navigate to the Project Folder

```bash
cd Online-Aptitude-Test-System
```

### 3. Configure Database

- Create a MySQL database
- Import the provided SQL file
- Update database credentials in the configuration file

### 4. Run the Project

If using XAMPP:

1. Place the project folder inside:

```text
htdocs/
```

2. Start:

- Apache
- MySQL

3. Open:

```text
http://localhost/Online-Aptitude-Test-System
```
